# 💻 Semester 1: C Programming Lab & Practice

This repository contains my C programs, lab assignments, and practice problems from my **First Year (Semester 1)** coursework.

## 📚 Syllabus & Folder Structure

- **`01-Basics/`** – Input/Output (`printf`, `scanf`), data types, operators, and typecasting.
- **`02-Control-Flow/`** – `if-else`, `switch-case`, loops (`for`, `while`, `do-while`), and star/number pattern printing.
- **`03-Arrays-and-Strings/`** – 1D & 2D arrays (matrix operations, sorting, searching) and string manipulation functions.
- **`04-Functions-and-Recursion/`** – Call by value vs. call by reference, scope rules, and recursive problems (factorial, Fibonacci, Tower of Hanoi).
- **`05-Pointers/`** – Pointer basics, pointer arithmetic, and dynamic memory allocation (`malloc`, `calloc`, `free`).
- **`06-Structures-and-Files/`** – `struct`, `union`, `typedef`, and basic File I/O operations.
- **`Lab-Assignments/`** – Official weekly college practical file programs.

## ⚙️ How to Compile and Run

Make sure you have the `gcc` compiler installed. Open your terminal and run:

```bash
# Compile the program
gcc program_name.c -o output

# Run the executable (Linux/macOS)
./output

# Run the executable (Windows)
output.exe
```
